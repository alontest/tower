# 塔台 1.0.30（69）

- 策略组详情：点开任一策略组，可直接修改名称、策略类型和候选策略，节点组可直接修改节点名称匹配并实时预览；修改自动保存。
- 查看规则内容：策略组列出它包含的规则列表、来源和条数，点开可搜索每一条规则，并按「含子域名 / 仅此域名 / 关键词 / IP 段」分类查看。
- 添加网站：可在策略组里直接添加域名、关键词或 IP 段，这些规则最先匹配，刷新或更新规则方案不会丢失。
- 拖动排序：规则定制、规则首页和导出后的客户端面板顺序保持一致；拖动策略组会同时调整它的匹配优先级，若有网站因此改走别的组，会提示并可撤销。
- 修复首页地图展开或收起国家节点列表时，地图卡片轻微跳动的问题。

支持 iOS 17 及以上；Mac 安装包为 Apple silicon / Intel 通用版本。
